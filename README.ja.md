# CtrlHanabi

[English](./README.md) | **日本語**

`Ctrl` キーの連打でデスクトップに花火を打ち上げる、Windows 常駐型の WPF アプリケーションです。
透過オーバーレイを描画し、ロケットの上昇から炸裂、美しい残光表現までをデスクトップ上に重ねて表示します。

![CtrlHanabi デモ](./CtrlHanabi_v1.0.4.gif)

## 主な機能

- **通常花火の打ち上げ**: `Ctrl` キーのダブルタップで、マウスカーソルの位置に花火を打ち上げます。
- **スターマインの打ち上げ**: `Ctrl` キーのトリプルタップで、豪華なスターマインシーケンスを打ち上げます。
- **マウスカーソル追従**: 打ち上げ場所が現在のマウスカーソルの座標に追従します。
- **タスクトレイ常駐**: アプリケーションはタスクトレイに常駐し、バックグラウンドで動作します。
- **Windows 起動時の自動起動**: スタートアップ登録（レジストリ）の有効/無効をタスクトレイから切り替え可能です。
- **自動保存される設定**: キーの入力閾値や花火の演出などを詳細にカスタマイズできます。
- **マルチモニター対応**: スターマインを表示するディスプレイを個別に選択できます。

## 花火演出のバリエーション

- 打ち上げ時の煙や筒のビジュアル表現
- 3D 風の球状に広がるパーティクル拡散
- リアルな残光とグロー（光彩）エフェクト
- ランダムに切り替わる鮮やかな色彩
- **花火の種類 (ランダム生成)**:
  - 菊 (Chrysanthemum)
  - 牡丹 (Peony)
  - 冠菊 (Kamurogiku)
- **打ち上げ軌道演出**:
  - 通常の打ち上げ
  - 銀竜風の尾を引く上昇
  - 小花の途中開花

## 動作環境

- **OS**: Windows x64 (Windows 10 / 11)
- **フレームワーク/ランタイム**: .NET 10 (WPF)

## 使い方

1. `CtrlHanabi.exe` を起動します。
2. アプリケーションがタスクトレイに常駐します。
3. 任意の場所で `Ctrl` キーを素早く 2 回押すと、通常の花火が打ち上がります。
4. `Ctrl` キーを素早く 3 回押すと、スターマインが打ち上がります。

### 終了方法
- タスクトレイアイコンを右クリックし、メニューから **[終了]** を選択します。
- または、`Ctrl` キーを素早く 5 回連打すると、終了確認ダイアログが表示されます。

## タスクトレイメニュー

- **Windows起動時に実行**: レジストリ `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` を使用して自動起動を設定します。
- **毎時スターマインを打ち上げ**: 有効にすると、毎時 `59分30秒` に画面中央からスターマインを自動で打ち上げます。
- **設定をリセット**: 設定ファイルを初期状態に戻します。
- **終了**: アプリケーションを終了します。

## 設定と構成

### 設定ファイル
ユーザー設定は JSON 形式で以下のパスに保存されます。

- **保存先**: `%LocalAppData%\CtrlHanabi\settings.json`

#### 設定ファイルの例
```json
{
  "DoubleTapThresholdMs": 320,
  "CooldownMs": 500,
  "ParticleCount": 90,
  "ExplosionRadius": 110,
  "HourlyStarmineEnabled": false,
  "StarmineLaneLeftEnabled": true,
  "StarmineLaneCenterEnabled": true,
  "StarmineLaneRightEnabled": true,
  "StarmineDisplayIndex": 1,
  "UiLanguage": null
}
```

#### 各設定項目の説明
- `DoubleTapThresholdMs`: 連打（ダブルタップ/トリプルタップ）として検出するキー入力間の最大ミリ秒数。
- `CooldownMs`: 連続での打ち上げを抑制するクールダウン時間（ミリ秒）。
- `ParticleCount`: 花火の火花の数（パーティクル数）の基準値。
- `ExplosionRadius`: 爆発半径の基準値。
- `HourlyStarmineEnabled`: 毎時 `59分30秒` の時報スターマインを有効にするか。
- `StarmineLaneLeftEnabled` / `StarmineLaneCenterEnabled` / `StarmineLaneRightEnabled`: スターマインの各打ち上げレーン（左・中・右）の有効/無効。
- `StarmineDisplayIndex`: スターマインを描画するディスプレイ番号（1から始まるインデックス。範囲外の場合はメインモニターの `1` が使用されます）。
- `UiLanguage`: タスクトレイメニューの表示言語。`null` または `"auto"` で OS 言語から自動判別。明示指定時は `"ja"` または `"en"`。

*※設定画面のUIは用意されていないため、カスタマイズする際は設定ファイルを直接編集してください。*

### 動作制御 (環境変数)
環境変数を定義することで、レンダラーの挙動やログ出力を制御できます。

#### グラフィックス・物理演算の制御
未設定時の規定値はすべて `1` (有効) です。`0` を設定することで無効化（フォールバック）できます。

- `CTRLHANABI_D3D11`: `0` で Direct3D 11 パーティクルレンダラーを無効化します（ソフトウェア描画にフォールバック）。
- `CTRLHANABI_GPU_PHYSICS`: `0` で GPU を使用した物理演算を無効化します（CPU物理演算にフォールバック）。

#### ログ設定
Direct3D 11 関連の診断ログは `%LocalAppData%\CtrlHanabi\d3d11.log` に出力されます。

- `CTRLHANABI_LOG`: 全体ログ制御。`1` で有効、`0` で無効。
- `CTRLHANABI_D3D11_LOG`: 互換用。`CTRLHANABI_LOG` が未設定の時のみ参照され、`1` で有効。

**優先順位**:
1. `CTRLHANABI_LOG=0` の場合は常にログ無効。
2. `CTRLHANABI_LOG=1` の場合はログ有効。
3. `CTRLHANABI_LOG` 未設定時は `CTRLHANABI_D3D11_LOG` の設定に従う。

- **技術スタック**: C# / WPF (.NET 10), Direct3D 11 描画連携

## 注意事項 / 制限事項

- **プラットフォーム制限**: キーボード入力検知の実装都合上、動作対象は Windows x64 環境のみに限定されます (x86 では入力検知が不安定になる可能性があります)。
- **権限の分離 (UAC)**: アプリケーションは通常ユーザー権限で動作します。そのため、タスクマネージャーなどの管理者権限で実行されているウィンドウがアクティブな間は、OSのセキュリティ制限により `Ctrl` キーの連打を検知できません。すべての状況で検知させたい場合は、本ツールを管理者権限で実行するか、署名済みの `uiAccess` アプリケーションとして Windows の信頼済みフォルダに配置してください。
